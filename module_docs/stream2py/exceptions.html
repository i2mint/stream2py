stream2py.exceptions

Custom exception classes for stream2py

This module defines the exception hierarchy for stream2py, providing more specific and informative error messages than generic Python exceptions.

exception stream2py.exceptions.BufferError[source]

Base exception for buffer-related errors

exception stream2py.exceptions.BufferOverflowError[source]

Raised when buffer is full and auto_drop=False

exception stream2py.exceptions.ConfigurationError[source]

Raised when stream2py objects are misconfigured

exception stream2py.exceptions.InvalidDataError[source]

Raised when data doesn’t meet expected format or constraints

exception stream2py.exceptions.NoDataAvailableError[source]

Raised when no data is available and ignore_no_item_found=False

exception stream2py.exceptions.Stream2PyError[source]

Base exception for all stream2py errors

exception stream2py.exceptions.StreamAlreadyStoppedError[source]

Raised when operations require a running stream but stream has been stopped

exception stream2py.exceptions.StreamNotStartedError[source]

Raised when operations require a started stream but stream hasn’t been started
